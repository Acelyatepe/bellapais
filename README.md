## English

Bellapais is a restaurant website built with plain HTML, CSS and JavaScript. It has a home page and a full menu page. The site content is in Turkish. Some menu photos are still missing and will be added.

### Features

- Menu page with search
- Cart for selected dishes
- Dark mode
- Image slider, gallery and video section
- Reservation and contact forms
- Responsive design

### Built with

HTML · CSS · JavaScript

### Run locally

Open `index.html` in a browser.

## Deutsch

Bellapais ist eine Restaurant-Website, umgesetzt mit reinem HTML, CSS und JavaScript. Sie besteht aus einer Startseite und einer vollständigen Speisekarte. Die Inhalte der Seite sind auf Türkisch. Einige Fotos der Speisekarte fehlen noch und werden ergänzt.

### Funktionen

- Speisekarte mit Suche
- Warenkorb für ausgewählte Gerichte
- Dunkelmodus
- Bild-Slider, Galerie und Videobereich
- Reservierungs- und Kontaktformulare
- Responsives Design

### Technologien

HTML · CSS · JavaScript

### Lokal starten

`index.html` im Browser öffnen.
